# HPC-LAB

HPC lab assignments and C performance analysis projects.

## Performance analysis projects

See [Performance-Analysis-Projects](Performance-Analysis-Projects/) for the complete C source, setup commands, actual benchmark results, correctness checks and GNU gprof report.

- [Sorting algorithms](Performance-Analysis-Projects/Sorting-Algorithms/): Bubble, Selection and Merge Sort.
- [OpenMP scheduling](Performance-Analysis-Projects/OpenMP-Scheduling/): static, dynamic and guided scheduling.

The GitHub Actions workflow compiles, tests and profiles both projects on Ubuntu and saves the verified reports.

The original four assignment documents are retained alongside the project folder.
